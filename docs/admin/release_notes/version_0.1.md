# v0.1 Release Notes

## [v0.1.0] - 2026-06-07

### Added

- Added the initial Nautobot Wireless Cellular SoT App for Nautobot `>=3.1.0,<4.0.0`.
- Added `CarrierProfile`, `CellularRouter`, `SIMCard`, and `CellularOperationalSnapshot` models.
- Added Wireless Infrastructure navigation, dashboard, CRUD pages, filters, forms, and tables.
- Added Device detail integration for cellular desired and observed state.
- Added REST API, GraphQL types, summary endpoint, and Prometheus text export.
- Added Pydantic normalization and DiffSync adapter scaffolding.
- Added app configuration schema, documentation, issue templates, workflows, and release automation.
