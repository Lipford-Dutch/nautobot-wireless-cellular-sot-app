# App Use Cases

## SIM Assignment Control

Track desired SIM-to-router slot assignments and surface conflicts when observed ICCIDs disagree.

## Carrier and APN Governance

Define reusable carrier profiles and roaming intent for automation pipelines.

## External Automation

Query REST or GraphQL for Ansible inventory generation, provisioning workflows, and compliance checks.

## Observability

Use the Prometheus endpoint for bounded-cardinality latest state. Store historical signal and traffic telemetry outside Nautobot.
